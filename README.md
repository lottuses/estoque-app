# Estoque App

Aplicação interna de gestão de estoque e catálogo para uma empresa de móveis planejados, voltada ao uso de funcionários e a pedidos de grande volume para clientes específicos. Desenvolvida sob demanda, com versão web e build Android a partir do mesmo código.

## Funcionalidades

- Cadastro e consulta de produtos (catálogo)
- Controle de entradas e saídas de estoque
- Pedidos por cliente com grandes quantidades
- Login com perfis de acesso para funcionários
- Uso no celular (build Android)

## Tecnologias

Angular · TypeScript · Ionic · Capacitor · ESLint · Karma
